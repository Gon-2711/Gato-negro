# 🗄️ Supabase

**Supabase** es la plataforma Backend-as-a-Service (BaaS) utilizada como motor principal de base de datos PostgreSQL para el [[SISTEMA_ERP_Y_BOT|ERP Gato Negro]]. 
Garantiza la persistencia de datos en la nube, sincronización en tiempo real y la seguridad criptográfica (BCrypt) del sistema, reemplazando la base de datos local antigua (SQLite).
